# HireHub

HireHub is a back-end job portal application currently under development using Spring Boot and MySQL.

## Current Progress

* Spring Boot project initialized
* Maven project structure created
* Database connected using `application.properties`
* GitHub repository setup completed

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Maven

### Database

* MySQL

## Project Status

This project is currently in the initial development phase. Upcoming updates will include:

* User authentication
* Job posting APIs
* Job application system
* Role-based access
* Frontend integration
* Deployment

## Folder Structure

```bash
src/
 ├── main/
 │    ├── java/
 │    └── resources/
 │         └── application.properties
 └── test/
```

## Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/HireHub.git
```

### Run Project

```bash
mvn spring-boot:run
```
